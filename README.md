# 情绪配图（emotion_pics）

文字聊天容易干。这个插件不改变回复内容，只在合适的情绪点补一张图——说到开心配开心的，说到委屈换一张，不多话，也不刷屏。

## 怎么用

1. 在面板里传图，给每张选一个情绪：开心、委屈、生气、害羞、困、无语都行
2. 给情绪配关键词，比如「开心」对应「好耶、哈哈、笑死」
3. 回复里出现这些词，就按概率从对应情绪里抽一张附上

## 它是什么

不是随机丢图，也不是表情包刷屏器。它只做一件事：在你说到某种情绪的时候，递上一张合适的图。

- 图库自己管，传什么用什么
- 概率能调，不想太频繁就拧小
- 每个情绪能单独开关
- 图片存在本机，不走第三方

## 功能

- 情绪图库：上传、预览、删除
- 关键词触发
- 每个情绪独立开关
- 触发概率可调
- 单次回复配图数量上限
- 图片大小限制

## 安装

1. 把 `astrbot_plugin_emotion_pics` 放到 AstrBot 数据目录的 `plugins/` 下
2. 重启 AstrBot
3. 打开面板，传图、标情绪

## 配置

- 情绪关键词：每个情绪一组词
- 触发概率：0~1，默认偏低，免得刷屏
- 单次最多配几张：默认 1
- 图片大小：默认单张 5MB

## 数据放在哪

```
<数据目录>/plugin_data/astrbot_plugin_emotion_pics/
├─ images/
└─ emotions.json
```

## 说点实话

- 图得自己准备，插件不带图库
- 配图是概率行为，不保证每条都有
- 只支持 AstrBot 4.x
