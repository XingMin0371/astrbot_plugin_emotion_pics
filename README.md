# 情绪配图（emotion_pics）

**让回复有表情：说到开心就配一张开心的图，说到委屈就换一张。**

文字聊天容易干。这个插件不改变回复内容，只在合适的情绪点补一张图——不多话，也不刷屏。

## 一句话卖点

- **按情绪配图**，不是随机丢图
- **概率可控**，不想太频繁就调低
- **图库自己管**，面板上传、预览、删除
- **纯本地**，图片不外传

## 怎么用

1. 面板里上传图片，给每张图选一个情绪（开心 / 委屈 / 生气 / 害羞 / 困 / 无语…）
2. 给情绪配关键词，比如「开心」对应「好耶、哈哈、笑死」
3. 回复命中关键词时，按概率从对应情绪里抽一张附上

## 功能

- 情绪图库：上传、预览、删除
- 关键词触发
- 每个情绪单独开关
- 触发概率可调
- 单次回复配图数量上限
- 图片大小限制

## 优点

- **轻**：只做配图，不干预对话
- **准**：按情绪选图，不是随机图
- **可控**：概率、关键词、情绪都能调
- **干净**：图片存本机，不上传第三方

## 安装

1. 把 `astrbot_plugin_emotion_pics` 放到 AstrBot 数据目录的 `plugins/` 下
2. 重启 AstrBot
3. 打开插件面板，上传图片并标注情绪

## 配置

- 情绪关键词：每个情绪一组词
- 触发概率：0~1，默认偏低，避免刷屏
- 单次最多配几张：默认 1
- 图片大小：默认单张 5MB

## 目录

```
<数据目录>/plugin_data/astrbot_plugin_emotion_pics/
├─ images/
└─ emotions.json
```

## 限制

- 图片需要自己准备，插件不带图库
- 配图是概率行为，不保证每条都有
- 只支持 AstrBot 4.x
