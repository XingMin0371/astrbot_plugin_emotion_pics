# 情绪配图（emotion_pics）

按情绪给回复配图：在面板里上传图片、标注情绪，配置关键词后，说到对应情绪时有概率附上一张图。

## 思路

纯文字聊天容易干。这个插件不改变回复内容，只在合适的情绪点补一张图：

1. 面板维护“情绪 → 图片”的图库，每张图带情绪标签；
2. 配置里给情绪配关键词（如“开心、好耶、哈哈”）；
3. 回复命中关键词时，按概率从对应情绪图库里抽一张附上。

## 功能

- 面板上传 / 删除 / 预览图片
- 按情绪分类管理图库
- 关键词触发 + 概率控制
- 每个情绪可单独开关
- 纯本地存储，不上传第三方

## 优点

- **轻**：只做配图，不干预对话
- **可控**：概率、关键词、情绪都能调
- **直观**：面板里看图管理
- **干净**：图片存本机插件数据目录，不外传

## 安装

1. 把 `astrbot_plugin_emotion_pics` 放到 AstrBot 数据目录的 `plugins/` 下
2. 重启 AstrBot
3. 打开插件面板，上传图片并标注情绪

## 配置

- 情绪关键词：每个情绪一组词
- 触发概率：0~1
- 单次回复最多配几张：默认 1
- 图片大小限制：默认单张 5MB

## 目录

```
<数据目录>/plugin_data/astrbot_plugin_emotion_pics/
├─ images/
└─ emotions.json
```

## 限制

- 图片需要自己准备，插件不带图库
- 配图是概率行为，不保证每条都有
- 只支持 AstrBot 4.x
