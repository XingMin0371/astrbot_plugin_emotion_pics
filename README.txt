# 情绪配图（emotion_pics）

纯文字聊久了，容易显得干。这个插件不改变回复内容，只在合适的情绪点补一张图——说到开心配开心的，说到委屈换一张，不多话，也不刷屏。

## 怎么用

1. 在面板里传图，给每张选一个情绪：开心、委屈、生气、害羞、困、无语都行
2. 给情绪配关键词，比如「开心」对应「好耶、哈哈、笑死」
3. 回复里出现这些词，就按概率从对应情绪里抽一张附上

## 它是什么

不是随机丢图，也不是表情包刷屏器。它只做一件事：在你说到某种情绪的时候，递上一张合适的图。

- 图库自己管，传什么用什么
- 概率能调，不想太频繁就拧小
- 图片存在本机，不走第三方

## 功能

- 情绪图库：上传、预览、删除
- 关键词触发
- 触发概率可调
- 每小时配图数量上限
- 图片大小限制

## 安装

1. 把 `astrbot_plugin_emotion_pics` 放到 AstrBot 数据目录的 `plugins/` 下
2. 重启 AstrBot
3. 打开面板，传图、标情绪

## 配置

- 情绪关键词：每个情绪一组词
- 触发概率：0~100%，默认 30
- 每小时最多几张：默认 3
- 图片大小：单张 8MB；同一会话冷却 5 分钟

## 数据放在哪

```
<数据目录>/plugin_data/astrbot_plugin_emotion_pics/
├─ images/
├─ thumbs/
└─ index.json
```

从旧版本升级：第一次启动会自动把 `<数据目录>/emotion_pics/` 合并进来，旧目录清空，不用手动搬。

## 已知限制

- 图片需要自己准备，插件不带图库
- 配图是概率行为，不保证每条都有
- 只支持 AstrBot 4.x
- 单张图片上限 8MB，只接受 png / jpg / gif / webp / bmp

## 三分钟上手

1. 在 AstrBot 插件市场安装并启用
2. 打开插件面板，上传几张图
3. 给每张图选一个情绪，填几个关键词
4. 在设置里调触发概率，保存

之后聊天碰到对应情绪，插件会按概率附一张图；不改变回复内容。

## 图库功能

- 分页、搜索、标签筛选、批量删除
- 标签编辑，索引可导出/导入
- 回收站：删除进回收站，可恢复/清空，保留 1-30 天
- 缩略图由 `state` 接口同步返回 base64，缓存写入数据目录的 `thumbs/`，不再写插件目录
- 可选自动转 WebP（默认关闭），GIF 保留原图
- 支持群、个人、时段黑名单
- 全选本页/批量删除
